按钮怎么进去的：ui-workspace 没给标题行留插槽（那一行的搜索 / 筛选 / 新建工作区是硬编码渲染的，筛选状态也关在它私有的 view store 里），所以按钮是挂进标题行的原生节点 —— 唯一依赖是 CSS 模块的本地类名 sectionHeader（构建哈希前缀会变、本地名稳定），找不到锚点时整块隐身。
什么时候出现：当前可见的会话行**全是归档行**时（即「仅显示已归档」这类视图），且提示里带个数；视图里还有未归档的行、或一个归档会话都没有时隐身。
删除过程：串行逐个删，弹窗里显示「正在删除…」；部分失败会留在弹窗里报「已删除 x 个，y 个失败」，已删的不会回来，剩下的可以再点一次。
不做 undo：物理删除不可恢复，确认成本靠红按钮 + 数量提示，而不是骗人的撤销提示。
